# Week 6 Assignment

This repository contains five Java OOP exercises. Each question is stored in
its own folder and includes the Java source file and compiled class files.

## Questions

| Folder | Topic |
| --- | --- |
| `M1` | Library Inventory Management |
| `M2` | Payroll Salary Management |
| `M3` | Employee Profile Creation |
| `M4` | Exam Hall Ticket Reference Management |
| `M5` | Employee and Company Information Management |

## Run an exercise

From the repository root, compile and run any question with:

```text
cd M1
javac Main.java
java Main
```

Replace `M1` with `M2`, `M3`, `M4`, or `M5` as needed.

All five exercises have been compiled and tested successfully.
